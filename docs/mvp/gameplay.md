# Игровые механики

Все числа взяты из `src/game/balance.ts` и `src/game/newGame.ts`. Скорости заданы в сутках, деньги в долларах, нефть и вода в баррелях (bbl), газ в тысячах кубических футов (mcf).

## Время

- На скорости 1× одна игровая сутки равна одной секунде. Доступны скорости 0 / 1× / 2× / 5×; пробел ставит на паузу.
- Симуляция идёт шагом 0.1 суток, офлайн-досчёт — шагом 0.5 суток.
- Офлайн-прогресс ограничен 365 игровыми сутками. Без предела долгое отсутствие выкачивало бы месторождения до дна.
- Игра начинается 1 января 1985 года. Автосохранение каждые 15 секунд, а также при сворачивании вкладки и закрытии страницы.

## Основной цикл

1. Скважины дают жидкость. Её количество ограничено пластом (давление) и насосом (лифт).
2. Каскад объектов (сепаратор, вода, резервуары, вывоз) может «задушить» скважины — это узкое место.
3. Нефть продаётся по рыночной цене. Затраты: эксплуатация, электричество, вода, транспорт, факел.
4. Деньги идут на скважины, лифты, объекты и разведку. Добыча тем временем сама падает, обводнённость растёт.

## Пласт

У каждого месторождения есть скрытые параметры: начальные запасы нефти (OOIP) и коэффициент извлечения (RF).

```
RF = rfBase + rfFrac + 0.18 · floodMaturity        извлекаемые запасы R = OOIP · RF
x  = Np / R                                         выработка (Np — накопленная добыча нефти)
P  = (1 − x · (1 − 0.6 · flood))^n                  нормированное пластовое давление
```

Добыча зависит от состояния пласта (выработки), а не от времени. Формула `q ∝ (1 − x)^n` даёт гиперболическую кривую Арпса с `b = 1 − 1/n`. Поэтому апгрейды, заводнение и офлайн-досчёт складываются корректно: у кривой нет «часов», которые можно сбить.

- Стартовое месторождение Old Barrow: OOIP 6 млн bbl, rfBase 0.15, n = 1.5, к старту уже добыто 360 тыс. bbl (x ≈ 0.4).
- У открытых месторождений n случайный от 1.3 до 2.0.

### Скважина

```
жидкость из пласта   = pi · P · (1 + stim)          pi — продуктивность скважины (bbl/d при P = 1)
производительность   = capacity(лифт) · kСостояния  для фонтана умножается ещё на P²
жидкость             = min(жидкость из пласта, производительность)
нефть = жидкость · (1 − wc),   вода = жидкость · wc,   газ = нефть · GOR / 1000
```

Если пласт может дать больше, чем вытягивает насос, скважина помечается как упёршаяся в лифт («LIFT LIMITED» в панели).

### Обводнённость

```
wc = clamp(wcMax · sigmoid((x − x50′) / width) + wcBias, 0, 0.99)
x50′ = wcX50 − 0.25 · floodMaturity
```

У Old Barrow: wcX50 = 0.42, width = 0.12, wcMax = 0.97, на старте wc ≈ 44%. У каждой скважины есть своё смещение `wcBias` (σ = 0.05): некоторые скважины обводняются раньше других. В карточке скважины показана её дневная прибыль, отсюда и решение «держать или глушить».

## Способы бороться с падением

### Лифт (artificial lift)

| Лифт | Производительность, bbl/d жидкости | Стоимость | Монтаж | Эксплуатация, $/сут | Электричество, $/bbl | Износ, /сут | Требует |
|---|---|---|---|---|---|---|---|
| Фонтан (natural flow) | 700 · P² | 0 | сразу | 20 | 0 | 0.0008 | — |
| Штанговый насос (качалка) | 260 | $60k | 3 сут | 60 | 0.35 | 0.0022 | — |
| Газлифт | 1200 | $150k | 4 сут | 140 | 0.15 | 0.0012 | компрессор |
| ЭЦН (ESP) | 3500 | $280k | 5 сут | 260 | 0.55 | 0.0045 | технология ESP |

Новые скважины начинают фонтаном. Когда давление падает, фонтан иссякает, и нужен насос.

### ГРП (frac)

- Даёт `stim += 1.4 · 0.7^k`, где k — номер стадии. Эффект затухает как `exp(−t / 300 сут)`.
- Максимум 3 стадии. Стоимость $220k · 1.35^k, скважина простаивает 6 суток.
- Каждая стадия прибавляет месторождению +0.5% к RF, суммарно не больше +3%.

### Заводнение (waterflood)

- Нужны технология Waterflood, насосы закачки и хотя бы одна скважина, переведённая под закачку (injector).
- Ёмкость закачки = min(мощность насосов, число нагнетательных скважин · 1500 bbl/d). Сначала закачивается попутная вода, недостающую берут из источника за $0.15/bbl.
- Для каждого месторождения считается компенсация отбора `VRR = закачка / отбор жидкости`. Поддержка давления `flood` стремится к `min(1, VRR)` с постоянной времени 60 суток.
- Зрелость заводнения `floodMaturity` догоняет `flood` с постоянной 365 суток и никогда не уменьшается: вытесненная нефть остаётся вытесненной.
- Итог: давление выше, RF растёт (до +0.18), но обводнённость наступает раньше.
- Нагнетательную скважину можно вернуть в добычу за ту же цену. Это защищает от тупика, когда все скважины переведены под закачку.

## Каскад

```
Скважины → Сепаратор ─┬─ Нефть → Резервуары → Вывоз (трубопровод, потом грузовики)
                      ├─ Вода  → Закачка → Поглощающая скважина (SWD) → Водовозы
                      └─ Газ   → Компрессор (продажа) → остаток на факел
```

Ограничения за шаг:
- сепаратор: суммарная жидкость не больше его мощности;
- вода: не больше суммы закачки, SWD и водовозов;
- нефть: `(ёмкость резервуаров − запас + вывоз за шаг, если идут продажи) / dt`.

Без технологии SCADA все скважины душатся одинаковым коэффициентом `k = min(1, ограничения / потребность)`. Со SCADA ограничения заполняются по возрастанию обводнённости: первыми душатся самые обводнённые скважины. Узкое место — то ограничение, которое сработало первым. Оно подсвечивается красным в панели и маяком на сцене.

| Объект | Уровни мощности | Стоимость уровней |
|---|---|---|
| Сепаратор, bbl/d жидкости | 600 → 1.5k → 4k → 10k → 25k | 0 / $70k / $260k / $900k / $2.8M |
| Резервуары, bbl | 1.5k → 5k → 15k → 40k → 100k | 0 / $45k / $160k / $520k / $1.6M |
| Нефтевозы | +150 bbl/d за штуку, до 40 | $18k · 1.14^n |
| Трубопровод, bbl/d | 0 → 6k → 20k | $1.4M / $4.0M |
| Водовозы | +250 bbl/d за штуку, до 40 | $15k · 1.14^n |
| SWD, bbl/d | 0 → 2.5k → 8k → 20k | $200k / $650k / $1.9M |
| Насосы закачки, bbl/d | 0 → 1.5k → 5k → 12k → 30k | $160k / $480k / $1.3M / $3.2M |
| Компрессор, mcf/d | 0 → 800 → 3k → 10k | $220k / $650k / $1.7M |

Переменные затраты:

| Статья | Ставка |
|---|---|
| Вывоз грузовиком | $3.50/bbl |
| Вывоз трубопроводом | $0.70/bbl |
| Водовозы | $1.80/bbl |
| SWD | $0.35/bbl |
| Закачка | $0.25/bbl |
| Факел (штраф) | $0.30/mcf |
| Выручка за газ | $2.80/mcf |

У каждого уровня объекта есть и постоянная плата в сутки. Хаб сам по себе стоит $200/сут.

## Рынок

```
смена режима:     с вероятностью 1/260 в сутки target ← U(42, 115)
база:             base → target, постоянная 90 сут
шум (OU):         n += −n·dt/15 + 0.03·√dt·N(0,1);   price = base · eⁿ
давление продаж:  impact += продано / глубина рынка;  затухание 6 сут;  не больше 40%
реализуемая цена = price · (1 − impact)
глубина рынка    = 300k + [0, 900k, 2.5M] в зависимости от уровня трубопровода
```

Режимы продаж:
- **Auto** — продавать всё, что позволяет вывоз.
- **Floor** — продавать, только если реализуемая цена не ниже порога.
- **Hold** — копить. Когда резервуары полны, скважины душатся.

Если долго копить, а потом сбросить запас, цена заметно просядет.

## Износ и обслуживание

```
износ за сутки = wear(лифт) · (0.3 + 0.7 · загрузка)        загрузка = жидкость / номинал лифта
коэффициент производительности = 1, если состояние ≥ 0.5, иначе 0.5 + состояние
шанс отказа за сутки при состоянии < 0.35: (0.35 − состояние) · 0.5
```

- **Обслуживание (service)**: мгновенно, $3000 + 15% цены лифта · (1 − состояние).
- **Ремонт отказавшей скважины**: max($20k, 35% цены лифта), 4 суток.
- **Бригада обслуживания** (технология, $400/сут): сама обслуживает всё ниже 50% и сама запускает ремонт отказавших.

## Разведка

- Карта 24×16 клеток, блоки 4×4 (всего 24 блока). Хаб в клетке (4, 8), Old Barrow в (5, 8). Домашний блок с самого начала покрыт старой 2D-сейсмикой.
- **Рельеф**: равнина, холмы, болото, озеро. Множитель стоимости бурения 1 / 1.3 / 1.6, в озере бурить нельзя.
- **Нефтеносные зоны (plays)**: 4 гауссовых пятна.

  | Зона | Сила | Множитель размера |
  |---|---|---|
  | Скромная, у хаба | 0.32 | ×1 |
  | Средняя | 0.35–0.5 | ×1.5 |
  | Средняя | 0.35–0.5 | ×1.6 |
  | Богатая, на дальнем востоке | 0.45–0.6 | ×2.6 |

  Априорная вероятность нефти в клетке: `prior = min(0.85, Σ + 0.02)`.
- **Лиды** — потенциальные ловушки нефти. Лид появляется в клетке с вероятностью `0.04 + 0.3 · prior`. Скрытые параметры лида:

  | Параметр | Распределение |
  |---|---|
  | Шанс успеха (CoS) | `clamp(prior · U(0.5, 1.1) + 0.02, 0.03, 0.7)`; исход бросается заранее |
  | OOIP | lognormal(3.5 млн · размер, σ = 0.85) |
  | rfBase | U(0.12, 0.2) |
  | pi | lognormal(380, σ = 0.35) |
  | GOR | U(300, 1400) |
  | Множитель стоимости скважин | `1 + размер · U(0.3, 0.8)`: богатые зоны глубже, бурить дороже |

- **Сейсмика 2D**: $150k, 15 суток. Видит около 70% лидов, оценка шанса ±0.18, на тепловой карте шум 0.12.
- **Сейсмика 3D** (технология за $600k): $380k, 30 суток. Видит все лиды, оценка шанса ±0.06, плюс оценка размера P90/P50/P10 (σ = 0.9).
- **Разведочная скважина (wildcat)**: $700k · множитель рельефа · множитель глубины (×1.2 там, где лида нет), 20 суток. Буровая одна. В клетке без лида всегда пусто. Результат показывается баннером: DRY HOLE, DISCOVERY или GUSHER! (если P50 больше 1.5 млн bbl).
- **Обустройство месторождения**: `(450k + 60k · расстояние до хаба) · 1.8^(обустроено − 1)`, 25 суток. Нужна технология Well pad. Хаб принимает до 5 месторождений. Скважина-первооткрывательница становится первой добывающей, куст рассчитан на 4 скважины.

### Оценка запасов P90 / P50 / P10

```
σ   = σ0 · (0.08 + 0.92 · e^(−6 · Np/R))      σ0 = 0.5 у Old Barrow, 0.7 у открытий
P50 = R · e^(bias · σ)                       bias ~ N(0,1) один раз на месторождение
P90 = P50 · e^(−1.2816 σ),   P10 = P50 · e^(+1.2816 σ)
```

По мере добычи разброс сужается, а P50 сходится к правде. Когда растёт RF (заводнение, ГРП), оценка тоже подрастает.

## Что видно на сцене

- **Хаб**: сепараторы (их число растёт с уровнем), резервуары со шкалой заполнения, ёмкости для воды, компрессор, насосы закачки, SWD с прудом, вагончик-офис, факел с пламенем и дымом (размер пламени зависит от сжигаемого газа).
- **Кусты**: тип скважины виден по оборудованию.

  | Тип | Вид |
  |---|---|
  | Штанговый насос | Качалка, анимированная: балансир, головка, шатуны, кривошип; темп качания зависит от загрузки |
  | Фонтан, газлифт, ЭЦН, нагнетательная | Фонтанная арматура своего цвета; у ЭЦН — шкаф управления |
  | Бурится | Вышка |
  | Идёт ремонт или работа на скважине | Малая вышка и жёлтый маяк |
  | Отказ | Красный маяк |

- **Трубы и дороги**: выкидные линии с точками потока, грузовики на дороге (ездят, только пока идут продажи), трубопровод на опорах.
- **Маяк узкого места** горит над сепаратором, резервуарами или водой.
