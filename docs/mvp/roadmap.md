## Известные проблемы и ограничения

| Проблема | Комментарий |
|---|---|
| В конце первого слоя копится $100M+ при нехватке трат | Нужен второй слой или дорогие поздние апгрейды (см. [balance.md](balance.md)) |
| Офлайн ограничен 365 сутками | При 1 сут/с потолок достигается уже через 6 минут отсутствия. Нужно решение по темпу |
| Миграции сохранений пишутся вручную | `migrate()` в `save.ts` умеет v1 → v2. Каждое изменение формы стейта — поднять `SAVE_VERSION` и дописать шаг, иначе игра сбросится |
| Новые скважины домашнего месторождения называются `Old-2`, `Old-3`, а первая — `Barrow-1` | Префикс берётся из первого слова названия месторождения («Old Barrow»). Найдено при работе над переводом, не исправлено |
| Русские тексты не вычитаны специалистом | Термины подобраны по отраслевой практике (ЭЦН, ГРП, ППД, ЦПС, поглощающая скважина), но стоит показать нефтянику |
| Нет банкротства | Деньги могут уйти в минус, покупки тогда блокируются. Тупик смягчён возвратом нагнетательных скважин в добычу |
| Одна буровая на разведку, бурение на кустах параллельно без лимита | Может стать механикой («купить вторую буровую») |
| Подписи кустов на сцене мелкие на общем плане и огромные при зуме | Нужна компенсация масштаба |
| В карточке клетки строка «Size P90 / P50 / P10» переносится | Косметика |
| Слой `lines` в `SiteView` пока пустой | Убрать или использовать |
| Мобильная вёрстка базовая | Игра рассчитана на десктоп |
| FPS на реальной видеокарте не мерился | В headless WebGL программный; JS тратит меньше 1 мс на кадр |
| Шрифты грузятся из сети | Без сети подставятся системные |

## Сделано после MVP: русский язык и подсказки

- Русский язык как опция: переключатель в меню-шестерёнке (там же «Сохранить игру» и «Новая игра»), по умолчанию по языку браузера. Устройство описано в [architecture.md](architecture.md#локализация).
- Журнал и причины отказа хранятся как ключ с параметрами (`SAVE_VERSION = 2`), поэтому переводятся и старые записи. Записи из сохранений v1 остаются на английском.
- Заголовки в русском интерфейсе набраны Fira Sans Extra Condensed: у Barlow Condensed нет кириллицы.
- Газ в русском интерфейсе — в тыс. м³, газовый фактор — в м³/барр.
- Глоссарий: около 50 терминов (сепаратор, обводнённость, P90/P50/P10, ГРП, узкое место, структура…) объясняются карточкой при наведении. Кнопки в карточке ещё и говорят, почему недоступны.
