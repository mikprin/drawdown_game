## Известные проблемы и ограничения

| Проблема | Комментарий |
|---|---|
| В конце первого слоя копится $100M+ при нехватке трат | Нужен второй слой или дорогие поздние апгрейды (см. [balance.md](balance.md)) |
| Офлайн ограничен 365 сутками | При 1 сут/с потолок достигается уже через 6 минут отсутствия. Нужно решение по темпу |
| Нет миграций сохранений | Любое изменение формы стейта требует поднять `SAVE_VERSION`, а это сбрасывает игру |
| Записи журнала хранятся готовым английским текстом | Мешает переводу (см. ниже) |
| Нет банкротства | Деньги могут уйти в минус, покупки тогда блокируются. Тупик смягчён возвратом нагнетательных скважин в добычу |
| Одна буровая на разведку, бурение на кустах параллельно без лимита | Может стать механикой («купить вторую буровую») |
| Подписи кустов на сцене мелкие на общем плане и огромные при зуме | Нужна компенсация масштаба |
| В карточке клетки строка «Size P90 / P50 / P10» переносится | Косметика |
| Слой `lines` в `SiteView` пока пустой | Убрать или использовать |
| Мобильная вёрстка базовая | Игра рассчитана на десктоп |
| FPS на реальной видеокарте не мерился | В headless WebGL программный; JS тратит меньше 1 мс на кадр |
| Шрифты грузятся из сети | Без сети подставятся системные |

## Оценка: русский перевод как опция

Сложность средняя, работа в основном механическая. Лучше делать раньше, пока текстов немного.

**Объём.** Около 250 строк для пользователя:

| Где | Что |
|---|---|
| `src/ui/*` | Панели |
| `balance.ts` | Названия и описания лифтов, объектов, технологий |
| `actions.ts` | Причины, по которым действие недоступно |
| `sim.ts`, `actions.ts` | Записи журнала |
| `objectives.ts` | Цели |
| `format.ts` | Единицы, месяцы |
| `site.ts`, `mapView.ts` | Подписи на сцене |
| `main.ts` | Модалки |

**План:**
1. `src/i18n/` со словарями `en.ts` и `ru.ts`, функция `t(key, params)`. Русские множественные формы (1 сутки / 2 суток, 1 скважина / 5 скважин) через `Intl.PluralRules('ru')`.
2. Переключатель EN/RU в верхней панели. Выбор хранится в localStorage отдельно от сохранения, по умолчанию берётся из `navigator.language`. При переключении панели перестраиваются.
3. Журнал хранит не текст, а `{ key, params }`, тогда старые записи тоже переведутся. Это меняет форму стейта: нужен `SAVE_VERSION = 2` и простая миграция (старые записи оставить как есть).
4. `Result.reason` превратить в код с параметрами (`{ code: 'needCash', cost }`). Сейчас `ActionButton` вытаскивает цену регуляркой из английского «Need $X».
5. Шрифт заголовков: **у Barlow Condensed нет кириллицы** (проверено по подмножествам Google Fonts). Для RU нужен другой узкий шрифт с кириллицей, например Roboto Condensed или Oswald. У IBM Plex Mono кириллица есть.
6. Вёрстка: русский текст на 20–30% длиннее. Узкие места — кнопки в левой панели шириной 330 px, сетка лифтов, кнопки апгрейдов в каскаде. Нужно пройтись скриншотами.
7. Термины: ЭЦН, ГРП, ППД / заводнение, обводнённость, куст, сепаратор, факел, ликвидация, разведочная скважина. Единицы: барр., барр./сут, тыс. ф³. Для крупных чисел — «тыс.» и «млн» или оставить k/M.

**Трудоёмкость:** несколько часов работы агента. Половина уйдёт на вынос строк и словари, вторая половина — на журнал, коды причин, шрифт и проверку вёрстки. Названия месторождений (Old Barrow, Ash Creek…) можно оставить как имена собственные.
